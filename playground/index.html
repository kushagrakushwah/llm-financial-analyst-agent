GLiNER Interactive Entity Extraction Lab

Generalist and Lightweight Model for Named Entity Recognition (Zaratiana et al.)
Step 1: Input Encoding
Joint Tokenization
Contract text and arbitrary candidate labels are formatted together into the bidirectional DeBERTa backbone.
[CLS] Labels [SEP] Tokens [SEP]
Step 2: Span Representations
Token Boundary Pairing
Every candidate span of length $k \le 12$ is computed by concatenating start token and end token representations with span length embeddings.
h_span = [h_start ; h_end ; len_emb]
Step 3: Label Representation
Dynamic Schema Vectors
Labels are not fixed classes in a linear head; they are natural language words projected into the shared embedding space.
v_label = MLP(BERT(label_str))
Step 4: Dot-Product Matching
Bilinear Scoring
Every span is scored against every label using a dot product with sigmoid activation. No softmax over classes, enabling multi-label detection.
Score = Sigmoid(h_span • v_label) > θ

TabPFN Interactive Tabular Foundation Lab

Prior-data Fitted Networks for Tabular Data (Hollmann et al., Nature / ICLR)
Step 1: Synthetic Priors
Offline Pre-Training
TabPFN was pre-trained on millions of synthetic datasets generated by random structural equation models, causal graphs, and Bayesian priors.
P(D) ~ Causal Structural Models
Step 2: In-Context Learning
Dataset as a Sequence
Both training samples $(x_i, y_i)$ and query samples $x_{test}$ are passed together through attention layers. No tree splitting or gradient descent.
[x_1, y_1, ..., x_n, y_n, x_test]
Step 3: Single Forward Pass
Instant Bayesian Posterior
In under 1 second on CPU, the self-attention mechanism performs exact Bayesian inference approximation, predicting posterior class probabilities.
P(y_test | D_train, x_test) in 0.5s
Step 4: Zero Hyperparameter Tuning
No Overfitting Loop
Unlike XGBoost or CatBoost which require tuning learning rate, depth, and L2 regularization across 50 trials, TabPFN requires zero tuning.

Production Python Integration Code

Drop-in snippets to use GLiNER and TabPFN in your own automated pipelines
from gliner import GLiNER

# 1. Load fine-tuned financial checkpoint or zero-shot base
model = GLiNER.from_pretrained("models/gliner_financial")

# 2. Define any target labels dynamically
labels = ["contracting_party", "liability_cap", "penalty_rate"]

# 3. Extract exact character spans with confidence threshold
entities = model.predict_entities(contract_text, labels, threshold=0.45)
for ent in entities:
    print(f"{ent['label']}: '{ent['text']}' [{ent['start']}:{ent['end']}] ({ent['score']:.2f})")
