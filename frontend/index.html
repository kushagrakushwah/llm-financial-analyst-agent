Production Architecture: Two-Pass Hierarchical & Context Routing
Why pairing dynamic context taxonomies with two-pass GLiNER beats flat single-level NER
Step 1 & 2: Context Router & Taxonomy

Dynamic Context Classification & Schema Injection

Instead of hardcoding a single static label list, the lightweight router classifies the document into its functional category (Vendor MSA, Employment Contract, Credit Facility, Commercial Lease) in under 10ms. The matching parent and child label sets are injected into GLiNER dynamically on the fly.

Step 3 & 4: Two-Pass Cascaded Extraction

Parent Clause Segmentation & Child Span Stitching

Pass 1 segments the document into coarse parent clauses (e.g., Termination, Liability, Compensation). Pass 2 executes fine-grained extraction inside each clause text, stitching relative local offsets back to exact global document coordinates with fallback handling for unclassified clauses.
